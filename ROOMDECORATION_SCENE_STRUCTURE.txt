===============================================
Material Shader Properties
===============================================

MAT_Silk_New (Satin Shader):
├── Base Color: User-selected (8 presets)
├── Smoothness: 0.9
├── Anisotropy: 0.7
├── Normal Map: Optional
└── Emission: None

MAT_Cotton_New (Cotton Shader):
├── Base Color: User-selected (8 presets)
├── Smoothness: 0.2
├── Normal Map: Optional
└── Emission: None

MAT_Denim_New (Layered Shader):
├── Base Color: User-selected (8 presets)
├── Layer 1: Base pattern
├── Layer 2: Overlay pattern
├── Blend Mode: Multiply
└── Normal Map: Optional

MAT_Leather_New (Satin Shader):
├── Base Color: Brown (fixed)
├── Smoothness: 0.6
├── Normal Map: Optional
└── Emission: None


===============================================
Data Flow
===============================================

User Input:
    ↓
UI Toolkit (Arrow Buttons)
    ↓
RoomDecoratorController
    ↓
Material Instancing (new Material())
    ↓
Renderer.material assignment
    ↓
Shader applies color
    ↓
Visual update in 3D scene


Camera Input:
    ↓
InputManager (OnMouseDrag, OnMouseScroll)
    ↓
OrbitCameraController
    ↓
Transform.position/rotation update
    ↓
Camera view changes


Scene Transition:
    ↓
RoomDecoratorController.OnBackClicked()
    ↓
ServiceLocator.Get<ISceneLoaderService>()
    ↓
await LoadMainMenuAsync()
    ↓
MainMenu scene loaded


===============================================
Performance Breakdown
===============================================

Geometry:
├── Floor: 2 tris (Plane)
├── Walls (x4): 48 tris (Cubes)
├── Curtains (x2): 4 tris (Quads)
├── Rug: 2 tris (Plane)
├── Cushions (x3): 36 tris (Cubes)
├── Table: 12 tris (Cube)
├── TableCloth: 2 tris (Plane)
└── Total: ~106 tris (primitives only)

Lighting:
├── Directional Light: 1
├── Point Lights: 2
└── Total: 3 lights

Draw Calls:
├── Estimated: 10-15 (4 materials + UI)
└── Batching: Possible with same materials

Memory:
├── Textures: Minimal (procedural shaders)
├── Materials: 4 base + instances
└── Meshes: Unity primitives (shared)
